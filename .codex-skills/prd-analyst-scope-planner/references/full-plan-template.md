## 18. Final Prompt for Coding AI Agent

Include this section exactly:

## Scope Control

You must only implement features described in the PRD and the approved task list.

Do not:
- Add extra features
- Redesign unrelated UI
- Refactor unrelated files
- Change unrelated backend logic
- Modify unrelated database schema
- Install unnecessary packages
- Change authentication unless required
- Touch payment logic unless required
- Touch deployment config unless required
- Rewrite the project structure unless required

If you find a missing requirement, stop and document it as an open question instead of guessing.

If PRD updates an existing project, include:

## Existing Project Safety Rules

1. Inspect existing folder structure.
2. Identify related files only.
3. Avoid touching unrelated modules.
4. Preserve existing working behavior.
5. Check current schema before migration changes.
6. Avoid duplicate routes/columns/components.
7. Keep changes small and scoped.
8. Test affected flow only.

## Do Not Touch Unless Required

- Authentication
- Payment gateway
- Global layout
- Existing dashboard navigation
- Existing unrelated database tables
- Deployment config
- Environment config
- Existing completed features
